## 1. Übung PHP – Cheat Sheet

Zuerst haben wir die PHP-Grundlagen mit dem Tutorial von w3schools wiederholt. Wenn ich bei etwas genauer nachschauen wollte, haben wir im offiziellen PHP-Handbuch nachgelesen. Daraus haben wir mir folgendes Cheat Sheet mit den wichtigsten Grundlagen zusammengestellt.

### 1.1 Syntax & Ausgabe 

```php
<?php
echo "Hallo Welt";      
?>
```

- Jede Anweisung endet mit `;`
- Kommentare: `// einzeilig` oder `/* mehrzeilig */`
- PHP-Code kann direkt in HTML eingebettet werden

### 1.2 Variablen & Datentypen 

```php
$text  = "Hallo";        // String
$zahl  = 42;             // Integer
$komma = 3.14;           // Float
$wahr  = true;           // Boolean
$liste = array(1, 2, 3); // Array
```

- Variablen beginnen immer mit `$`
- Groß-/Kleinschreibung zählt: `$name` ≠ `$Name`

### 1.3 Strings 

```php
$s = "Hallo " . $name;  // Verketten mit .
$s = $s . "!";          // etwas anhängen
echo $s[0];             // erstes Zeichen
strlen($s);             // Länge des Strings
```

### 1.4 Operatoren 

| Art | Operatoren |
|---|---|
| Rechnen | `+  -  *  /  %` |
| Zuweisung | `=  +=  -=  ++  --` |
| Vergleich | `==  !=  <  >  <=  >=` |
| Logisch | `&&` (und), `\|\|` (oder), `!` (nicht) |
| Verketten | `.` |

### 1.5 Verzweigungen 

```php
if ($x > 0) {
    echo "positiv";
} elseif ($x < 0) {
    echo "negativ";
} else {
    echo "null";
}

switch ($tag) {
    case "Mo":
        echo "Montag";
        break;
    default:
        echo "anderer Tag";
}
```

### 1.6 Schleifen 

```php
for ($i = 0; $i < 10; $i++) {
    echo $i;
}

while ($i < 10) {
    $i++;
}

foreach ($liste as $wert) {
    echo $wert;
}
```

### 1.7 Funktionen 

```php
function addiere($a, $b) {
    return $a + $b;
}

echo addiere(3, 4);     // 7
```

### 1.8 Arrays 

```php
$noten = array(1, 2, 3);
$noten[] = 4;           // Element anhängen
echo $noten[0];         // erstes Element: 1
count($noten);          // Anzahl Elemente

$person = array("name" => "Flo", "klasse" => "4AHITS"); // assoziativ
echo $person["name"];
```

### 1.9 Formulare 

```html
<form method="post">
    <input type="text" name="name">
    <input type="submit" value="Senden">
</form>
```

```php
if (isset($_POST["name"])) {   // wurde das Formular abgeschickt?
    echo $_POST["name"];
}
```

| Variable | Inhalt |
|---|---|
| `$_POST` | Formulardaten mit `method="post"` |
| `$_GET` | Daten aus der URL bzw. `method="get"` |
| `$_SESSION` | Daten, die über mehrere Seitenaufrufe erhalten bleiben |

Wenn mehrere Eingabefelder den Namen `name="note[]"` haben, kommen sie in PHP als Array an.

### 1.10 Sessions 

```php
session_start();               // ganz am Anfang der Datei
$_SESSION["zaehler"] = 0;      // Wert speichern
echo $_SESSION["zaehler"];     // Wert lesen
```

### 1.11 Zufallszahlen 

```php
rand(1, 100);           // Zufallszahl von 1 bis 100
```

### 2.1 Notenverwaltung

**Anforderungen**

-  Mehrere Noten über ein Formular eingeben
-  Noten in einem Array speichern
-  Durchschnitt, beste/schlechteste Note, Anzahl positiver Noten
-  Ausgabe als HTML-Tabelle

**Umsetzung**

Im Formular habe ich fünf Eingabefelder, die alle den Namen `note[]` haben. Dadurch kommen die Noten in PHP gleich als Array an . Mit einer `foreach`-Schleife gehe ich alle Felder durch und speichere nur die Noten, die nicht leer sind und zwischen 1 und 5 liegen, in meinem Array `$noten`.

Die Auswertung mache ich ebenfalls in einer `foreach`-Schleife. Da in Österreich 1 die beste und 5 die einzige negative Note ist, ist die kleinste Zahl die beste Note und alles bis 4 ist positiv. Den Durchschnitt berechne ich mit Summe durch Anzahl. Die Ausgabe erfolgt mit `echo` als HTML-Tabelle.

**Code (`noten.php`)**

```php
<h1> Wiviele Noten hast du? </h1>

<?php
 
if(isset($_POST["Anzahl"]))
    {
    $anzahl=$_POST["Anzahl"];
?>

        for($i=0;$i<$anzahl;$i++)
            {
                echo "<input type=number name='Noten[]'>";
            }
    ?>
 
    <button type=submit>Button</button>
</form>
 
 
 
 
 
<?php
    }
 
 
$noten=[];
```

### 2.2 Passwort-Generator

**Anforderungen**

-  Länge über ein Formular festlegen
-  Zufälliges Passwort erzeugen
-  Optionen: Groß-/Kleinbuchstaben, Zahlen, Sonderzeichen

**Umsetzung**

Für jede Option haben wir eine Checkbox gemacht. Mit `isset()` prüfen wir, ob sie angehakt ist. Wenn ja, hängen wir die passenden Zeichen an einen String an, in dem am Ende alle erlaubten Zeichen stehen.

Danach wähle ich in einer `for`-Schleife so oft ein zufälliges Zeichen aus, wie die Länge angibt. `rand()` liefert mir eine zufällige Position im String und mit `$zeichen[$zufall]` holen wir das Zeichen an dieser Stelle. Wenn die Länge nicht zwischen 4 und 64 liegt oder keine Option gewählt ist, wird eine Fehlermeldung ausgegeben.

**Code (`passwort.php`)**

```php
<?php
// Passworz-Generator

$passwort = "";
$fehler = "";

if (isset($_POST["laenge"])) {
    $laenge = $_POST["laenge"];

    // Erlaubte Zeichen je nach angehakten Optionen zusammenbauen
    $zeichen = "";
    if (isset($_POST["gross"])) {
        $zeichen = $zeichen . "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    }
    if (isset($_POST["klein"])) {
        $zeichen = $zeichen . "abcdefghijklmnopqrstuvwxyz";
    }
    if (isset($_POST["zahlen"])) {
        $zeichen = $zeichen . "0123456789";
    }
    if (isset($_POST["sonder"])) {
        $zeichen = $zeichen . "!@#$%*?-_+=";
    }

    if ($laenge < 4 || $laenge > 64) {
        $fehler = "Die Länge muss zwischen 4 und 64 liegen.";
    } elseif ($zeichen == "") {
        $fehler = "Bitte mindestens eine Option auswählen.";
    } else {
        // Zufällige Zeichen aneinanderhängen
        for ($i = 0; $i < $laenge; $i++) {
            $zufall = rand(0, strlen($zeichen) - 1);
            $passwort = $passwort . $zeichen[$zufall];
        }
    }
}
?>
<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Passwort-Generator</title>
</head>
<body>
<h1>Passwort-Generator</h1>

<form method="post">
    Länge: <input type="number" name="laenge" value="12"><br>
    <input type="checkbox" name="gross" checked> Großbuchstaben<br>
    <input type="checkbox" name="klein" checked> Kleinbuchstaben<br>
    <input type="checkbox" name="zahlen" checked> Zahlen<br>
    <input type="checkbox" name="sonder"> Sonderzeichen<br>
    <input type="submit" value="Generieren">
</form>

<?php
if ($fehler != "") {
    echo "<p style='color:red'>" . $fehler . "</p>";
}
if ($passwort != "") {
    echo "<h2>Dein Passwort:</h2>";
    echo "<p><b>" . $passwort . "</b></p>";
}
?>
</body>
</html>
```

Das Problem bei diesem Spiel war, dass das PHP-Skript bei jedem Absenden des Formulars neu ausgeführt wird. Dadurch würde bei jedem Tipp eine neue Zufallszahl erzeugt werden. Deshalb speichere ich die Zahl und die Anzahl der Versuche in der Session [1].

Wenn noch keine Zahl in der Session steht oder der Button „Neues Spiel“ gedrückt wurde, erzeuge ich mit `rand(1, 100)` eine neue Zahl und setze den Zähler auf 0. Bei jedem Tipp erhöhe ich den Zähler und vergleiche den Tipp mit `if / elseif / else` mit der gespeicherten Zahl.
